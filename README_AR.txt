# MARCO_RX6 PS4 HEN — واجهة عربية

موقع ثابت HTML/CSS/JavaScript، متجاوب للجوال والكمبيوتر، قابل للنشر على GitHub Pages.

## المحتويات
- `index.html` الصفحة الرئيسية
- `style.css` التصميم الأسود والأحمر
- `script.js` قائمة إصدارات النظام والتفاعل داخل الصفحة

## تجربة الموقع
افتح `index.html` في المتصفح. لا يحتاج إلى تثبيت أو خادم.

## النشر على GitHub Pages من الجوال
1. فك ضغط ZIP.
2. أنشئ مستودعًا جديدًا على GitHub باسم `MARCO-RX6-PS4-HEN`.
3. ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js` إلى جذر المستودع، وليس مجلد ZIP نفسه.
4. افتح Settings ثم Pages.
5. تحت Build and deployment اختر Deploy from a branch، ثم `main` و`/(root)`، وبعدها Save.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## ملاحظة مهمة
هذه واجهة معلومات فقط. لا تحتوي على exploit أو ملفات HEN ولا تنفذ تفعيلًا حقيقيًا. اختيار الإصدار يعرض ملاحظة توافق عامة فقط؛ لا تعرض القائمة أن كل الإصدارات مدعومة.
